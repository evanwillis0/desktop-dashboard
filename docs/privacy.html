Privacy policy

desktop-dashboard · Last updated November 15, 2026

desktop-dashboard is a personal tool that runs only on its developer's own Mac and is used only with the developer's own accounts. It has no servers, no user accounts, and no other users.

What data it accesses

  • Gmail (read-only): sender, subject, a short preview, date, and unread status of recent inbox messages, plus unread counts.
  • Google Calendar (read-only): titles, times, and locations of upcoming events.

It never sends, modifies, labels, or deletes email or calendar events.

How the data is used

The data is used only to display a snapshot on the owner's own desktop. It is not used for advertising, profiling, analytics, or training any model, and it is not sold.

Where the data is stored

  • Sign-in tokens are stored in the macOS Keychain on the owner's computer.
  • The most recent snapshot is cached in a local file on the same computer so the dashboard can show it immediately after login.

Nothing is uploaded to any server operated by the developer or shared with third parties.

Google API Services User Data Policy

desktop-dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from Google Account → Third-party connections. Deleting the app's Keychain entries and cache file removes all locally stored data.
